## 上线边界

本机没有百炼 API Key，也没有获准向真实客户发送测试消息，因此连接测试、真实窗口点击标定、人工模拟批准和测试账号小流量发送必须由操作者完成。软件默认停在影子观察，不会因更新或重启自动发送。
