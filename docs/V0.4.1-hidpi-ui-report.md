# AgentDesk 0.4.1 高分辨率界面优化报告

## 目标

本次更新在不改变业务逻辑和安全门规则的前提下，统一提升 WPF 桌面界面的字号、控件尺寸、留白、对比度和 Windows 高 DPI 适配。目标屏幕为 1920×1080 与 2560×1440，并覆盖 Windows 100%、125% 和 150% 显示缩放。

## 全局尺寸规范

| 用途 | 规范 |
| --- | --- |
| 正文 | 16 DIP，行高 25，Normal/400 |
| 辅助文字 | 14 DIP，行高 22 |
| 按钮与输入控件 | 16 DIP，最小高度 44 |
| 复选框紧凑高度 | 32 DIP |
| 区域标题 | 20 DIP，行高 28，SemiBold |
| 页面标题 | 28 DIP，行高 38，SemiBold/Bold |
| 导航项 | 最小高度 48 |
| 表格行与表头 | 52 DIP |
| 卡片内边距 | 24 DIP |
| 基础间距 | 8 / 12 / 16 / 24 / 32 DIP |
| 主内容最大宽度 | 1920 DIP |

WPF 的 DIP 会跟随 Windows 显示缩放转换为物理像素。例如 16 DIP 在 125% 和 150% 下分别按 20 和 24 个物理像素栅格化。

## 布局与 DPI 处理

- 使用全局资源字典维护字号、行高、控件高度、间距和颜色，页面不再散落 8–13 DIP 的小字号。
- 页面级滚动区域约束到实际窗口宽度，星号列会随可用空间伸缩；长页面使用纵向滚动，尺码表格保留独立横向滚动。
- 主窗口默认 1500×900 DIP、最小 1200×680 DIP；导航区域在低高度窗口中独立滚动。
- 主内容设置最大宽度并保留对称页面边距，避免 2K/更宽屏幕出现难以阅读的超长行。
- 应用清单启用 `PerMonitorV2,PerMonitor`，支持窗口跨不同 DPI 显示器时重新缩放。
- 使用布局舍入、设备像素吸附和 ClearType 文本渲染，减少非整数缩放时的模糊边缘。
- 日志列加入宽度和文本省略保护，字段再长也不会覆盖相邻列。

## 验证清单

1. Windows 设置 → 系统 → 屏幕，将分辨率设为 1920×1080 或 2560×1440。
2. 分别选择 100%、125%、150% 缩放；每次修改后关闭并重新打开 AgentDesk。
3. 最大化窗口，并把窗口缩小到允许的最小尺寸。
4. 依次查看 9 个导航页面以及“记忆体/技能中心”两个页签。
5. 确认页面标题、辅助文字、按钮和输入框完整；长页面可纵向滚动；尺码表可横向滚动；日志列不重叠。
6. 在不同缩放比例的两台显示器之间拖动窗口，确认窗口与文字会重新缩放且保持清晰。

## 自动化保护

集成测试会检查关键字号、控件高度、表格行高、内容最大宽度、页面宽度约束以及 Per-Monitor V2 清单，避免后续修改退回小字号或破坏 DPI 配置。
