# AI 智能售前 V1 控制台 UI 验收记录

验收日期：2026-08-17  
设计源：`design-prototype/index.html`

## 已验收页面

1. 智能体总览：总开关、运行表现、账号在线概览和账号运行状态。
2. 账号管理：账号启停、平台连接、执行流程、回复策略和运行事件。
3. 知识库与回复规则：知识分类、审核状态、适用范围和安全规则。

## 产品边界检查

- 控制台没有聊天窗口、客户会话列表、聊天气泡或回复编辑器。
- 控制台没有发送按钮，也不承担客服对话工作。
- 页面明确说明“所有对话在原客服平台处理”。
- 运行事件只展示账号、阶段、耗时、结果和错误信息，不展示聊天正文。
- V1 回复模式为“填入客服平台，由人工确认”。

## 交互与视觉验收

- 1440×900 三页视口截图通过，无裁切和重叠。
- 1280×800 下 `scrollWidth` 等于视口宽度，无横向溢出。
- 浏览器控制台：0 错误，0 警告。
- 全局“停止智能客服”后变为“启动智能客服”，运行账号显示为 0。
- “暂停此账号”后变为“启用此账号”。
- 设置开关正确更新 `aria-checked`，支持键盘访问。
- 导航、筛选、知识同步和配置操作均有状态反馈。
