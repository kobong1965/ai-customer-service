# AgentDesk 0.4.0 受控记忆体与技能中心交付报告

## 交付结果

- 新增三层记忆流程：当前请求上下文、自动脱敏候选、人工批准长期记忆。
- 真实影子/自动运行结果会生成抽象候选；模拟账号不记录，候选不会进入 Qwen。
- 长期记忆支持批准、编辑、启停、删除、搜索、筛选、导入和导出。
- 新增技能中心，支持新增、审核、编辑、启停、删除、导入、导出和恢复推荐技能。
- 内置 5 个原创安全改写的客服技能：回复质量复核、简洁友好语气、缺失信息追问、情绪与紧急度识别、激动客户降级处理。
- Qwen 每次最多加载 6 条相关长期记忆和 4 个技能，并输出 `skillsUsed` 供审计。
- 批准记忆或技能的内容/启停状态变化后，旧的正式模式批准立即失效。

## 安全边界

- 不保存客户聊天原文、截图、昵称、手机号、地址、订单正文或完整模型回复。
- “发送成功”只是处理结果，不会自动批准为正确经验。
- 记忆不能作为库存、价格、尺码、物流或售后事实的唯一依据。
- 技能是纯文本策略；包含 Shell、外部写入、绕过安全等高风险指令的导入会被拒绝。
- 模型引用未提供技能、不记录使用技能或仅引用记忆作为事实时，低风险回复会被强制转人工。
