# AI 智能售前 0.2.0 完善规格

状态：执行中  
日期：2026-08-17  
依据：`docs/V1-product-spec.md` 与 `docs/audit/0.2.0-baseline/AUDIT.md`

## 1. 目标

把现有原生 Windows 控制台从“能演示的纵向闭环”提升为“可由客服主管安全配置、验证、观察和试运行”的版本。对话仍全部发生在原客服平台；控制台只管理模型、窗口、知识、安全策略、运行状态和审计。

## 2. 核心原则

- 默认安全：应用每次启动服务均为停止状态，默认运行模式为影子观察。
- 分阶段开放：模型验证 → 知识准备 → 模拟验收 → 窗口校准 → 影子观察 → 自动发送。
- 代码门禁优先：模型不能改变风险词、发送额度、批准记录或点击范围。
- 最小数据：控制台不展示或持久化完整客户消息、地址、手机号、API Key。
- 可解释可恢复：每次阻断必须指出原因和下一步；配置改变后撤销旧批准。

## 3. 本次功能

### 3.1 上线准备与总览

- 展示五项准备状态：模型、知识、模拟、校准、运行策略。
- 每项可一键跳转到对应页面；显示“已完成 / 待完成”。
- 总览展示真实模式、当日发送数、当日转人工数、最近错误与当前窗口。
- 删除假搜索与假同步；顶部保留唯一总开关和紧急停止提示。

### 3.2 运行模式与安全策略

- `Shadow`：读取和决策，但不填入、不点击发送；记录“本可发送 / 应转人工”。
- `AutoSend`：仅低风险、有依据、满足批准与校准时允许发送。
- 默认 `Shadow`；切换至 `AutoSend` 需要完成模拟批准。
- 可配置每日发送上限（默认 100）、每分钟上限（默认 6）。
- 触达任一上限、连续 5 次故障或窗口尺寸漂移时自动停机。
- `Ctrl+Alt+S` 在应用有焦点时立即停止；界面持续显示停止入口。

### 3.3 可视化窗口校准

- 发现并选择真实客服窗口，显示标题、尺寸与进程。
- 截图在控制台中预览；操作者依次选择“标定输入框”与“标定发送按钮”，再直接点击预览图。
- 保存截图时的窗口宽高；运行前若宽高相对变化超过 12%，阻止自动发送并要求重校准。
- 支持测试截图、只点击输入框的无发送测试和恢复安全默认值。

### 3.4 知识库管理

- 新增、搜索、选择、编辑、启用/停用、删除。
- 标题 2–100 字，正文 2–4000 字，账号范围 1–80 字。
- 标题+正文重复时拒绝新增。
- JSON 导入和导出；导入只接受审核字段完整的知识并去重。
- 知识变化撤销正式模式批准。

### 3.5 结构化运行记录

- 以时间、阶段、账号、结果、严重性展示；不展示客户正文。
- 支持全部 / 错误 / 已发送 / 转人工筛选。
- 支持导出 JSONL；清理需二次确认。
- 本地最多保留 5000 条，读取最近 200 条用于界面。

### 3.6 多账号可审计性

- 视觉观察结构增加 `accountLabel`，运行记录带上识别到的账号标签。
- 不自动创建或修改店铺账号；未识别到账号标签时禁止正式发送。

### 3.7 交互与无障碍

- 任一时刻只显示一个导航选中态。
- 空知识、空日志、无窗口都有解释和下一步操作。
- 输入控件设置可读名称，状态栏标记为实时区域，隐藏页面不接收键盘焦点。
- 所有异步操作防重复点击，并在状态文案中说明进度。

## 4. 验收标准

1. 新安装且无 API Key 时，总览明确显示第一步和跳转入口。
2. 未批准模拟测试时，自动发送模式不可选；影子模式可在模型与校准有效后启动。
3. 影子模式不得调用 `SendReplyAsync`，但会记录决策结果。
4. 每日或每分钟额度耗尽时，当前消息不发送，服务停止并产生错误记录。
5. 窗口尺寸漂移超过 12% 时不点击平台控件。
6. 知识可完成增删改查与 JSON 导入导出，重复数据不会新增。
7. 日志可筛选、导出、确认清理；运行中不能无提示清理。
8. 原有 23 项测试继续通过，并新增影子模式、限速、尺寸保护、知识管理和日志管理测试。
9. Release 构建零警告；自包含发布覆盖原 `artifacts/AgentDesk-win-x64`，用户资料目录保持不变。
10. 在发布版中逐页实机检查并保存改版后截图。

## 5. 暂缓项

- 系统托盘和开机自启：有便利性，但会弱化“用户明确启动服务”的心智，本版不做。
- SQLite/全文索引：当前本地知识量小，JSON 足够；超过 1000 条后再迁移。
- 云端后台、远程控制、多机器调度：不属于当前单机上线目标。
- 模型集成编排（Hermes + DeepSeek + Qwen）：先让单模型结构化决策达到可测、可控、可回退，再评估成本和准确率收益。
