## 本次完成

- 接入阿里云百炼 OpenAI 兼容 Chat Completions。
- 支持截图 Base64 `image_url`、JSON 模式和可配置视觉模型。
- 默认模型 `qwen3.7-plus`，默认北京区域兼容接口；支持工作空间专属接口。
- API Key 使用 Windows 凭据管理器，不写入设置、日志或发布包。
- 增加模型设置、保存、删除密钥、真实连接测试和明确错误提示。
- 增加 Windows 可见窗口发现、窗口截图、相对坐标校准和无发送输入点测试。
- 增加多账号标签/未读会话视觉观察和受限点击区域。
- 增加发送前客户标识、最新客户消息、窗口标题和风险二次校验。
- 增加后台轮询、取消、指数退避、连续故障自动停止和持久化运行日志。
- 增加本地已审核知识库、账号适用范围、启用/停用、关键词检索和知识指纹门禁。
- 模型、密钥或安全策略变化会使已有人工测试批准失效。

## 安全门

正式启动必须同时满足：

1. API Key 已安全保存且 Qwen 连接测试成功。
2. 使用当前真实模型运行 5 个隔离必测用例并全部通过。
3. 操作者亲自检查结果并批准。
4. 客服平台窗口存在且相对坐标校准有效。

低风险决策仍必须包含非空回复和至少一条可验证依据。退款、投诉、赔偿、改价、改地址、支付、隐私、法律争议、绝对承诺、资料冲突或依据不足均转人工。
