# AgentDesk 0.2.0 发布版回归

日期：2026-08-17  
发布路径：`artifacts/AgentDesk-win-x64/AgentDesk.exe`  
产品版本：`0.2.0`

## 结果

- 1440×900：总览、窗口校准、知识库、运行策略、运行记录、测试实验室、模型设置均无裁切或重叠。
- 1280×720：总览核心状态、上线顺序、指标、导航和状态栏完整可用。
- 导航始终只有一个选中态；旧版假搜索和假“同步知识”已移除。
- 无 API Key 时启动影子观察会跳转模型设置并明确阻断。
- 未完成人工模拟批准时，自动发送模式无法生效并跳转测试实验室。
- 所有配置页空状态都有下一步说明；状态栏为实时可读状态。
