# AI客服 0.5.0

本版本增加完整的软件更新和 GitHub 公开发布能力。

- 在“系统设置”页检查 GitHub 最新正式版本。
- 下载 Windows x64 自包含 ZIP，无需预装 .NET。
- 安装前强制校验 SHA-256，拒绝损坏或被修改的更新包。
- 拒绝 ZIP 路径穿越，更新包只能写入应用目录。
- 使用暂存的新版本等待旧程序退出，原位覆盖后自动重启。
- 保留桌面快捷方式、`%LocalAppData%\AgentDesk` 用户数据和 Windows 凭据管理器中的 API Key。
- 增加公开仓库自动构建、测试、打包和 Release 工作流。

首次使用自动发送前，仍须在客服平台测试账号中完成人工模拟验收和小流量验证。
