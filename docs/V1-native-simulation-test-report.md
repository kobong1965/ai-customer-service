# 售前智服 V1 原生程序与模拟自动发送验收报告

日期：2026-08-17  
版本：0.1.0  
程序：`artifacts/AgentDesk-win-x64/AgentDesk.exe`

## 已实现

- .NET 10 WPF 原生 Windows 控制台。
- 隔离模拟客服平台，不触达任何真实客户。
- 手动输入模拟客户消息并自动处理。
- 低风险回复自动发送到模拟平台。
- 退款、投诉、改价、修改地址和无依据场景自动转人工，不发送。
- 5 个上线前必测用例。
- 必测用例全部通过且人工确认后才能保存正式模式批准记录。
- 批准记录绑定安全配置指纹；核心策略变化后自动失效。
- 真实平台适配器默认锁定，未批准时拒绝操作。
- 自包含 win-x64 单文件发布，不依赖系统安装 .NET。

## 自动化测试

```text
AgentDesk.Core.Tests:        6/6 通过
AgentDesk.IntegrationTests: 6/6 通过
总计:                      12/12 通过
警告:                       0
错误:                       0
```

覆盖内容：

- 低风险允许自动发送。
- 高风险即使开启自动发送也不会发送。
- 自动发送锁定状态不会发送。
- 未人工确认无法批准。
- 必测用例缺失无法批准。
- 配置指纹变化会重新锁定正式模式。
- 五个必测场景 5/5 通过，其中 2 个自动发送、3 个安全拦截。

## 桌面实机验收

- 自包含 `AgentDesk.exe` 可独立启动。
- 总览、账号管理、知识库、规则、日志、测试实验室和设置均可访问。
- 手动模拟“黑色 3XL 还有货吗？”后，界面显示智能客服回复且状态为“已自动发送到模拟客服平台”。
- 运行必测用例后，界面显示 5/5 通过。
- “测试通过并批准正式模式”在人工勾选前保持禁用。
