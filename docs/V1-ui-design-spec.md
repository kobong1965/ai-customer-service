# AI 智能售前 V1 UI 设计规格（Figma 绘制基线）

状态：控制台范围已确认，等待写入 Figma 画布。

## 1. 界面定位

这是智能客服的“控制台”，不是客服聊天软件。

- 控制台回答三个问题：智能客服是否运行、哪些账号被管理、发生了什么异常。
- 所有客户消息、聊天记录、回复输入和最终发送都留在原客服平台。
- 正式控制台不出现客户会话列表、聊天气泡、建议回复编辑器或发送按钮；独立“测试实验室”可展示隔离的模拟客服窗口，用于上线前验收自动发送。

设计关键词：安静、可信、低干扰、可审计、运行状态一眼可见。

## 2. 视觉方向

沿用参考图的极简黑白品牌、浅薄荷灰主面板、圆角卡片、黑色主按钮、细边框和紧凑数据表格。页面的记忆点是“运行信号棒”：图表中的黑色竖条代表当前唯一拥有平台操作权的任务，体现单线程安全控制。

## 3. 画布与布局

- 桌面主画布：1440×900。
- 最小适配：1280×720。
- 左侧栏：216 px；主内容区边距 18 px。
- 顶部工具栏：68 px。
- 主要栅格：12 列，列间距 16–20 px。
- 大卡片圆角：18 px；普通卡片：12 px；按钮/筛选：8–10 px。

## 4. 色彩与字体

| 语义 | 色值 | 用途 |
|---|---|---|
| Ink | `#111312` | 主文字、选中导航、主按钮 |
| Canvas | `#F6F8F6` | 页面背景 |
| Mint Surface | `#EEF5F0` | 运行总览和安全状态 |
| Surface | `#FFFFFF` | 表格、编辑区、普通卡片 |
| Border | `#E2E7E3` | 卡片和控件边框 |
| Muted | `#6E7671` | 次级文字 |
| Success | `#2F9B68` | 运行中、已连接、成功 |
| Warning | `#E99231` | 等待人工、需要检查 |
| Danger | `#D95656` | 异常、已停止、紧急操作 |

中文首选 `Noto Sans SC`，本地原型使用 `Segoe UI Variable / Microsoft YaHei UI`。正文 12–14 px，标题 18–28 px，关键指标 32–40 px。

## 5. 页面范围

### Screen A：智能体总览

- 左侧：品牌、当前管理员、导航宫格、底部智能客服运行卡片。
- 顶栏：搜索账号/运行记录/设置、同步知识、全局启动或停止按钮。
- 上半区左侧：今日运行表现，展示分时处理数量、成功率和平均耗时。
- 上半区右侧：账号概览，展示在线账号数量和各账号今日处理量。
- 下半区：账号运行状态表，不展示客户或聊天正文。
- 表格字段：账号、平台连接、回复模式、最近动作、今日处理、运行状态、操作。

### Screen B：账号管理

- 左列：已接入的店铺账号、启用状态和平台连接状态。
- 右侧顶部：当前账号总状态和“暂停此账号”操作。
- 状态区：平台连接、自动化阶段、回复模式、今日处理量。
- 流程区：监测消息 → 校验账号 → 读取上下文 → 生成回复 → 填入平台。
- 配置区：账号启用、启动时自动监听、异常立即停止、自动发送模式和测试批准状态。
- 底部：最近运行事件，只展示阶段、结果、时间和错误码，不展示客户消息正文。

### Screen C：知识库与回复规则

- 左侧分类：商品知识、物流、售前、售后、禁用承诺。
- 顶部搜索、新增知识和导入按钮。
- 中间知识列表：标题、适用账号/商品、审核状态、更新时间。
- 右侧编辑区：正文、关键词、适用范围、风险等级和启用状态。
- 未经审核的内容不能被模型引用。

## 8. 样例文案

- 品牌：`售前智服`
- 总状态：`智能客服运行中 · 3 个账号`
- 全局动作：`停止智能客服` / `启动智能客服`
- 单账号动作：`暂停此账号` / `启用此账号`
- 回复模式：`低风险自动发送`
- 上线安全门：`模拟测试未通过` / `已通过并人工批准`
- 平台状态：`已连接`、`等待客服软件`、`界面需要重新校准`
- 事件：`回复已填入平台`、`高风险咨询已交给人工`、`账号校验失败，任务已停止`

## 9. 可访问性与交互

- 正文对比度至少 4.5:1，主要点击区域不小于 40×40 px。
- 状态同时使用文字、图标和颜色表达。
- 键盘可以完成导航、筛选、总开关、按账号开关和配置保存。
- 全局停止按钮始终可见，并提供明确的停止结果反馈。
- 停止智能客服不会退出软件或丢失配置。
- 危险操作需要与普通配置操作保持视觉区分。
