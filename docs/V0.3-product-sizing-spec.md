# Spec: 0.3.0 商品分类与尺码规则

## Assumptions

1. 一个商品链接可包含多个版型或版本，例如西裤常规版与加长版，必须分别建规则。
2. 商品链接只是本地匹配标识；本版本不抓取网页，也不从页面自动推断尺码表。
3. 用户录入并确认的尺码表才视为“已审核事实”，模型不得使用通用品类经验猜尺码。
4. 客服平台截图中能看到的商品标题、SKU 或链接作为商品标识；识别不清或版本不一致时转人工。
5. 尺码推荐允许先追问身高、体重、腰围或胸围；只有唯一命中一行规则时才允许给出明确尺码。

## Objective

为售前智服增加独立的商品分类与尺码规则库。客服主管可把商品链接归入裤装/上衣等品类，再细分阔腿裤、直筒裤、西裤、短袖、卫衣、外套和常规版/加长版等版本，并为每个版本维护独立尺码表。Qwen 仅能引用当前商品精确匹配且已审核启用的规则。

## Tech Stack

- .NET 10、C#、WPF
- 本机 JSON 原子写入存储，路径位于 `%LocalAppData%\AgentDesk`
- 现有 Qwen OpenAI 兼容接口与 Windows 屏幕观察适配器

## Commands

- Build: `.\.tools\dotnet\dotnet.exe build AgentDesk.sln -c Release`
- Test: `.\.tools\dotnet\dotnet.exe test AgentDesk.sln -c Release --no-build`
- Format: `.\.tools\dotnet\dotnet.exe format AgentDesk.sln --verify-no-changes --no-restore`
- Publish: `.\.tools\dotnet\dotnet.exe publish src\AgentDesk.App\AgentDesk.App.csproj -c Release -r win-x64 --self-contained true -o artifacts\AgentDesk-win-x64`

## Project Structure

- `src/AgentDesk.Core`：尺码资料、匹配结果和提供者契约
- `src/AgentDesk.Infrastructure`：本地尺码规则存储、校验、导入导出和指纹
- `src/AgentDesk.AI`：商品识别字段、尺码上下文和模型输出安全校验
- `src/AgentDesk.Automation`：发送前商品/版本二次复核
- `src/AgentDesk.App`：商品尺码管理、规则行编辑和人工试算
- `tests`：存储、匹配、模型接入与安全回退测试

## Code Style

```csharp
public sealed record ProductSizingProfile(
    string Id,
    string ProductUrl,
    string ProductKey,
    string Category,
    string Fit,
    string Variant,
    IReadOnlyList<SizeRecommendationRow> Rows,
    bool IsReviewed,
    bool IsEnabled,
    DateTimeOffset UpdatedAt);
```

- 领域对象不可变；UI 编辑行使用可观察对象。
- 所有输入先 Trim、长度校验，再写入临时文件并原子替换。
- 界面沿用现有黑白薄荷绿设计系统，保留键盘可操作、空状态和错误状态。

## Matching and Safety Rules

- 商品资料按账号范围过滤，再按标准化链接、SKU/商品标识精确匹配；标题只作为辅助词，不跨商品套用。
- 只有 `IsReviewed && IsEnabled` 的资料可进入模型上下文。
- 尺码问题的低风险自动回复必须在 `factsUsed` 中引用 `size:<profile-id>`。
- 未识别商品、版本不一致、没有规则、数据缺失、零行/多行命中时，禁止给出明确尺码；可追问信息或转人工。
- 自动发送前再次识别账号、客户、最新消息和商品标识；任一变化即取消发送。
- 任何新增、修改、停用、删除或导入都会撤销原正式模式批准。

## Testing Strategy

- Core/Infrastructure：字段校验、URL 规范化、账号过滤、精确匹配、重复检查、指纹变化、导入导出。
- AI：尺码问题注入匹配规则，未引用 `size:` 依据的低风险输出强制转人工。
- UI：1280×720 与 1440×900 无导航裁切；新增、编辑、停用、删除、试算、导入导出均有反馈。
- Release：构建零警告、全部自动化测试通过、原发布目录启动成功。

## Boundaries

- Always：保存真实来源链接；每个版本独立审核；变更后重跑模拟验收；不记录客户聊天正文。
- Ask first：联网抓取商品页、批量同步平台商品、修改真实客服平台数据。
- Never：按服装常识猜尺码；把一个款式规则套到另一款；在商品识别不确定时自动给出明确尺码。

## Success Criteria

1. 能为同一商品保存常规版和加长版两套互不覆盖的尺码表。
2. 支持裤装、上衣及自定义品类/版型；规则行支持身高、体重、腰围、胸围的可选上下限。
3. 可搜索、编辑、停用、删除、导入、导出，并能用客户测量值做人工试算。
4. Qwen 只收到当前商品匹配的已审核规则；无尺码事实引用时无法通过低风险门禁。
5. 正式发送前商品标识变化会取消发送。
6. 发布版继续使用既有 `artifacts/AgentDesk-win-x64/AgentDesk.exe` 和原本机数据目录。

## Open Questions

- 后续由用户提供真实商品链接和官方尺码表；当前版本不预填任何未经确认的尺码数据。
- 若平台截图长期无法稳定识别 SKU，可在后续版本增加商品卡片区域单独校准或 OCR 兜底。
