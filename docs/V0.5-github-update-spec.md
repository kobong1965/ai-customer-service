# Spec: 0.5.0 GitHub 自动更新与公开发布

## Objective

为 Windows 桌面应用“AI客服”增加可实际使用的软件更新能力，并将完整源码与 Windows x64 自包含程序发布到公开 GitHub 仓库。

操作者在“模型设置”页可以查看当前版本、检查 GitHub 最新 Release、阅读更新说明并下载安装。更新必须覆盖现有程序目录，随后从同一个桌面快捷方式继续使用；`%LocalAppData%\AgentDesk`、Windows 凭据管理器中的 API Key、客服数据、知识库、记忆体、技能和运行记录不得进入发布包，也不得在更新时被改写。

已确认的发布决策：

- 单一公开仓库同时保存源码和 Release。
- 正式仓库为 `kobong1965/ai-customer-service`。
- 本次是新增完整更新子系统，版本升级为 `0.5.0`。
- Windows 交付资产使用 ASCII 文件名，避免下载工具对中文文件名兼容不一致。

## Tech Stack

- .NET 10 / C# / WPF
- GitHub REST API（公开 `releases/latest`，不需要 GitHub Token）
- `System.IO.Compression` 解压更新包
- SHA-256 校验下载完整性
- GitHub Actions：Windows runner 构建、测试、打包和 Release

## Commands

```powershell
# 验证
& .\.tools\dotnet\dotnet.exe build .\AgentDesk.sln -c Release
& .\.tools\dotnet\dotnet.exe test .\AgentDesk.sln -c Release --no-build

# 本地发布包
& .\scripts\package-release.ps1 -Version 0.5.0

# 首次创建公开仓库并推送
gh repo create kobong1965/ai-customer-service --public --source . --remote origin --push

# 创建 Release
gh release create v0.5.0 .\release\AI-Customer-Service-win-x64.zip .\release\AI-Customer-Service-win-x64.sha256 --repo kobong1965/ai-customer-service --title "AI客服 0.5.0" --notes-file .\release\RELEASE_NOTES.md
```

## Code Style

继续使用现有 C# 命名、可空引用和异步命令模式。网络及文件操作返回明确状态，不在视图代码后置中实现业务逻辑。

```csharp
public async Task<UpdateRelease?> CheckForUpdateAsync(
    Version currentVersion,
    CancellationToken cancellationToken = default)
{
    var release = await GetLatestReleaseAsync(cancellationToken);
    return release.Version > currentVersion ? release : null;
}
```

界面沿用 `DesignTokens.xaml`、`CardBorder`、`PrimaryButton` 和全局字号/控件高度；按钮包含可见文字和 `AutomationProperties.Name`，下载中状态可读且不可重复触发。

## Testing Strategy

- 单元/集成测试使用 xUnit。
- 使用自定义 `HttpMessageHandler` 测试 GitHub JSON 解析，不访问真实网络。
- 覆盖新版本/无更新、缺少资产、SHA-256 不一致、ZIP 路径穿越、正常解压。
- 运行完整解决方案测试，确保现有客服安全门、模型、知识、尺码、记忆和技能功能不回归。
- 对本地正式包执行一次“旧目录 → 更新包 → 原目录”更新验证，并核对快捷方式目标和用户数据指纹。

## Boundaries

- Always：仅从 HTTPS GitHub Release 下载；校验 SHA-256 后才解压；更新前停止智能客服；保留原安装目录、快捷方式和用户数据。
- Ask first：改变仓库可见性、改用带 Token 的私有更新、改变用户数据目录或上传渠道。
- Never：提交 API Key、本机配置、客服聊天、日志、知识库/记忆体实际内容；从 ZIP 中执行额外脚本；接受目录穿越条目；静默绕过校验失败。

## Success Criteria

- 设置页显示当前 `0.5.0`，可以检查公开 GitHub 最新版本。
- 没有更新时给出明确提示；有更新时显示版本、说明和下载按钮。
- 下载后校验 `AI-Customer-Service-win-x64.sha256`，校验失败不安装。
- 更新进程退出旧程序、覆盖原目录并自动重启；同一个 `AI客服.lnk` 仍指向原目录。
- `%LocalAppData%\AgentDesk` 与 Windows 凭据不进入 ZIP，更新验证前后用户数据指纹一致。
- Release ZIP 在未安装 .NET 的 Windows x64 上可独立运行。
- `dotnet build` 零警告/零错误，全部自动化测试通过。
- GitHub 公开仓库、`v0.5.0` Release 和直接下载 URL 均可匿名访问。
