# AgentDesk 0.3.0 商品分类与尺码规则报告

日期：2026-08-17  
状态：功能代码与本地验证完成；等待录入真实商品链接和官方尺码表后进行平台测试账号验收

## 已完成

- 商品链接、截图可见商品标识/SKU、适用账号、品类、版型和版本独立建模。
- 同一商品支持常规版、加长版等多套规则，不会相互覆盖。
- 尺码行支持身高、体重、腰围、胸围上下限与备注；体重规则统一保存为 kg。
- 本地审核规则支持搜索、编辑、启停、删除、JSON 导入导出、重复校验和安全指纹。
- 人工规则试算可区分唯一命中、缺少测量数据、无匹配和多行重叠。
- Qwen 屏幕观察增加商品标识；只向模型注入当前账号和商品匹配的已审核启用规则。
- 尺码低风险回复必须引用精确 `size:` 规则；模型结果与本地唯一试算不一致时转人工。
- 真实发送前新增商品/版本标识二次复核，变化时取消发送。
- 尺码规则变化会撤销旧的正式模式批准。

## 验证边界

- 本版本不抓取商品网页，不内置任何未经用户确认的通用尺码建议。
- 真正上线前必须录入官方尺码表，并用平台测试账号验证截图中商品标题/SKU和版本能够稳定识别。
- 默认仍为影子观察；真实自动发送需要重新完成必测用例和人工批准。

- 自动化测试：38/38 通过。
- 格式检查：`dotnet format --verify-no-changes` 通过。
- 视觉回归：1440×900 与 1280×720 的总览、导航和商品尺码页通过实机检查。
- 原位发布：`artifacts/AgentDesk-win-x64/AgentDesk.exe` 产品版本 `0.3.0`，本机用户资料目录保持不变。
