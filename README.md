# AI客服

Windows 智能客服控制台，版本 `0.5.0`。客户对话始终留在原客服平台；本程序负责开关、Qwen 视觉识别、安全决策、商品分类与尺码规则、可审核记忆体、客服技能中心、可视化窗口校准、影子观察、低风险自动发送、运行审计和软件更新。

## 下载正式版

在 [GitHub Releases](https://github.com/kobong1965/ai-customer-service/releases/latest) 下载：

- `AI-Customer-Service-win-x64.zip`：Windows x64 自包含完整程序。
- `AI-Customer-Service-win-x64.sha256`：完整性校验文件。

解压 ZIP 后双击 `AgentDesk.exe`。程序显示名称和窗口标题为“AI客服”；内部文件名继续保留 `AgentDesk`，用于兼容既有快捷方式和本地数据。

## 直接运行

双击：

```text
artifacts/AgentDesk-win-x64/AgentDesk.exe
```

这是 Windows x64 自包含发布版，不要求电脑预装 .NET。设置、知识、测试批准和日志保存在当前 Windows 用户的 `%LocalAppData%\AgentDesk`，API Key 只保存在 Windows 凭据管理器。

## 软件更新

打开“系统设置”，在“软件更新”区域点击“检查更新”。有新版本时可直接下载并安装：

1. 软件从公开 GitHub Release 下载 ZIP 和 SHA-256 文件。
2. 校验通过后解压到 `%LocalAppData%\AgentDesk\Updates` 暂存区。
3. 新版本等待旧程序退出，覆盖原程序目录并自动重启。
4. 更新不会覆盖 `%LocalAppData%\AgentDesk` 用户数据，也不会读取或上传 Windows 凭据中的 API Key。

校验失败、Release 资产缺失或 ZIP 包含不安全路径时，软件会停止安装并保留当前版本。

## 首次启用（按顺序完成）

1. 打开“设置”，粘贴阿里云百炼 API Key，保留默认接口与 `qwen3.7-plus`，点击“保存并测试连接”。
2. 在“知识库”添加真实商品、库存或物流口径；只有已审核且启用的条目会提供给 Qwen。知识支持搜索、编辑、删除和 JSON 导入导出。
3. 涉及服装尺码时，在“商品尺码”中粘贴商品链接，填写客服截图可见的商品标题/SKU，再选择品类、版型、版本并录入官方尺码表。同一商品的常规版、加长版必须分别建立规则。
4. 选择一套已保存规则，在“人工规则试算”中输入身高、体重、腰围或胸围，确认唯一命中、缺资料和重叠区间的处理符合预期。
5. 打开“窗口校准”，刷新并选择客服平台。点击“测试截图并刷新预览”，依次选择“标定输入框”“标定发送按钮”，再直接点击截图中的真实位置，最后保存校准。
6. 在“运行策略”保留默认的“影子观察”，确认每日和每分钟限额后保存。影子模式会读取和决策，但绝不填入或发送。
7. 回到总览点击“启动影子观察”，使用真实平台测试账号观察一段时间，在“运行记录”检查账号标签、商品标识、阶段、影子结果和错误。
8. 准备自动发送时，打开“测试实验室”运行 5 个必测用例；人工检查 5/5 结果后勾选确认并批准。
9. 回到“运行策略”选择“低风险自动发送”。先用平台测试账号小流量试运行，再逐步开放正式账号。

## 正式运行流程

```text
屏幕变化 → Qwen 观察未读账号/会话 → 受限区域点击 → 读取当前截图
        → Qwen 生成结构化回复决策 → 代码安全门 → 发送前再次视觉核对
        → 低风险自动发送 / 高风险转人工
```

- 账号标签点击只允许在窗口顶部区域；会话点击只允许在左侧列表区域。
- 发送前必须再次确认客服账号标签、客户标识、最新客户消息和已识别商品标识一致。
- 回复必须是低风险、非人工接管、非空且包含可验证依据，否则不发送。
- 尺码回复必须引用当前账号、商品、版型与版本精确匹配的 `size:` 规则；本地代码会再次试算，模型尺码与唯一结果不一致时强制转人工。
- 客户测量数据不足时只能追问；无匹配、重叠区间或多版本未确认时不允许给出具体尺码。
- 达到日/分钟限额、连续 5 次故障或窗口尺寸漂移超过 12% 会自动停止；`Ctrl+Alt+S` 可紧急停止。
- 智能客服运行中禁止修改模型、知识、尺码规则、窗口校准和安全策略。
- 运行日志只保存阶段和结果，不保存 API Key 或完整聊天正文。

## 正式使用前仍需人工完成

- 在“商品尺码”中录入你提供的真实商品链接、截图可见标题/SKU 和官方尺码表；软件不会联网猜测或抓取尺码。
- 客服平台必须在实际窗口上完成截图点击标定；正式客户发送前必须先用影子观察和平台测试账号小流量验证。
- 如果更换 API Key、模型、知识或尺码规则，必须重新运行模拟验收并人工批准。

模型或密钥变化会撤销旧的人工测试批准并要求重新验收。不要在未重新测试的情况下直接替换生产模型。
